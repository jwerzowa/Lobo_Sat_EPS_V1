# LOBOSAT EPS Board

Design of the power board for LOBOSAT, the UNM Student Satellite Group's 1U cubesat. It will be one of three boards in the stack.

Goal: solar-powered, solderability (hand solder and hotplate), provide 3V3 and 5V, provide telemetry data that can be downlinked on the health status of the EPS system.

## What it does

- Takes power from 12x Anysolar SM141K10TF solar cells
- Charges a LG MJ1 18650 pack (2S2P, on Keystone clips) through an LT3652 MPPT charger
- Protects the battery with the S-8252AAC (primary, drives FS8205A cutoff FETs) and the BQ29209 (backup OVP + cell balancing), plus fuse + PTC
- Regulates the battery bus down to two separate rails using LMZM33602 buck modules: 3V3 (Rail A) and 5V (Rail B)
- Switches three subsystems (videography, telemetry, comms) through current-limited TPS2553 load switches
- Reports battery current, bus voltage and charge with the INA228, and solar/bus/mid-cell voltage and battery temperature with an ADS1015, over I2C
- Has an RBF switch (SS-5GL), which is mandated for cubesats in orbit, will need to work on chassis column depression switch for deployment in orbit
- Optional battery heater (all parts DNP for now)

## Working on it

Close KiCad, then:

```bash
python3 scripts/consolidate_libs.py   # after adding a download to libs/_downloads/
python3 scripts/gen_schematic.py      # after changing a connection in build_sheets()
K=/Applications/KiCad/KiCad.app/Contents/MacOS/kicad-cli
$K sch erc --severity-all -o out/erc.rpt EPS_Lobosat_V1.kicad_sch
$K sch export netlist --format kicadsexpr -o out/EPS_Lobosat_V1.net EPS_Lobosat_V1.kicad_sch
python3 scripts/check_netlist.py out/EPS_Lobosat_V1.net expected_nets.json
```

Once the drawing gets tidied by hand in KiCad, edit in KiCad from then on and stop re-running the generator.
